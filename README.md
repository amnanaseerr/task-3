# 📝 To-Do List Application – C++

A simple **To-Do List Application** implemented in **C++** that allows users to add tasks, view tasks, mark them as completed, and remove them.

## 🚀 Features

- **Add a Task**: Allows the user to add tasks with descriptions.
- **View Tasks**: Displays all tasks with their status (Completed or Pending).
- **Mark Task as Completed**: Allows the user to mark a task as completed.
- **Remove a Task**: Allows the user to remove a task by its index.
- **Exit**: Exits the program when selected.

## 🛠️ Technologies Used

- **C++** – Language used to implement the program.
- **STL (Standard Template Library)** – Utilized for the `vector` to store the tasks.

## 📁 How to Compile and Run

1. Clone or download the project folder.
2. Compile the C++ program using a compiler:
   ```bash
   g++ -o todo_list todo_list.cpp

3. Run the compiled program:
./todo_list
